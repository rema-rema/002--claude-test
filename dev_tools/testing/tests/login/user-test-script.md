# ユーザーテストスクリプト - Login機能

## 🎯 テスト目的
Login機能のモック認証システムが正常に動作することを確認する

## 🖥️ テスト環境
- **フロントエンド**: http://localhost:3000
- **バックエンド**: http://localhost:8000  
- **認証方式**: Mock Authentication
- **テストアカウント**: 
  - test@example.com / password123
  - admin@example.com / admin123

## 📋 テストシナリオ

### シナリオ 1: 正常ログイン
1. ブラウザでhttp://localhost:3000にアクセス
2. ログインページが表示されることを確認
3. 「テストユーザー」ボタンをクリック
4. フォームに自動入力されることを確認
5. 「ログイン」ボタンをクリック
6. ダッシュボードページに遷移することを確認
7. ユーザー情報が正しく表示されることを確認

### シナリオ 2: 手動入力ログイン
1. ログインページでフォームに手動入力
   - Email: admin@example.com
   - Password: admin123
2. 「ログイン」ボタンをクリック
3. ダッシュボードに遷移し、Admin Userとして表示されることを確認

### シナリオ 3: 無効な認証情報
1. 無効なメールアドレス・パスワードを入力
2. エラーメッセージが表示されることを確認
3. ログイン画面にとどまることを確認

### シナリオ 4: ログアウト
1. ダッシュボードで「ログアウト」ボタンをクリック
2. ログインページに遷移することを確認
3. 認証が無効になっていることを確認

### シナリオ 5: 認証ガード
1. 直接http://localhost:3000/dashboardにアクセス
2. ログインページにリダイレクトされることを確認
3. ログイン後に再度アクセス可能になることを確認

- [ ] テストアカウントボタンが動作する
