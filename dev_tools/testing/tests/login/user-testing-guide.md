# ユーザーテストガイド - ログイン機能

## 🎯 テスト目的

Google OAuth 2.0を使用したログイン機能の動作確認とユーザビリティ検証

## 📋 テスト準備

### 1. 環境起動
```bash
# Session 1環境を起動
./scripts/docker-manager.sh start session1

# フロントエンド・バックエンド両方を起動
./scripts/session-runner.sh session1 both dev
```

### 2. アクセス確認
- フロントエンド: http://localhost:3001
- バックエンドAPI: http://localhost:8001
- API仕様書: http://localhost:8001/docs

### 3. Google OAuth設定
実際のGoogle OAuth設定が必要です：
1. Google Cloud Consoleでプロジェクト作成
2. OAuth 2.0クライアント作成
3. `.env.session1`ファイルに以下を設定：
   ```bash
   GOOGLE_CLIENT_ID=your_actual_google_client_id
   GOOGLE_CLIENT_SECRET=your_actual_google_client_secret
   ```
