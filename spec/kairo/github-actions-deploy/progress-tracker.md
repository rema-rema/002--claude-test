## 1. プロジェクト経緯

### 1.1 発端
- **ユーザー要望**: 「リリースをGitHubを使う事でデプロイを自動化ってできるものなの？」
- **目的**: 手動デプロイから自動化への移行により、作業効率向上とヒューマンエラー削減

### 1.2 検討経過
1. **初期検討**: GitHub Actions vs Jenkins vs その他CI/CDツール比較
2. **Jenkins検討**: 
   - メリット: 完全無料、高機能、Claude Code での全設定可能
   - デメリット: サーバーリソース消費、保守工数
3. **最終決定**: GitHub Actions 採用
   - 理由: 完全無料(パブリックリポジトリ)、軽量、保守不要、モダン

### 1.3 環境構成の整理
- **現在環境**: Windows ホスト上の Linux ゲスト OS (仮想マシン)
- **将来環境**: Ubuntu 物理サーバー (検証環境用)
- **デプロイ対象**: `/home/rema/release/002--claude-test/`
