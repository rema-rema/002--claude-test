# VPN/DNS Access System 要件定義書

## 1. 概要
VPN接続環境下で独自ドメイン（home.poco）を使用したWebアクセスシステムの構築

## 2. 背景と目的

### 2.1 背景
- 家族全員がシンプルなURLでサービスにアクセスしたい
- ポート番号の入力を不要にしたい
- VPN経由でセキュアにアクセスしたい

### 2.2 目的
- VPN接続PCから `http://home.poco` でアクセス可能にする
- クライアント側の設定変更を不要にする
- 将来的に複数サービスを追加可能な基盤を構築する

## 3. 機能要件

### 3.1 必須要件
- **FR-001**: VPN接続PCから `http://home.poco` でアクセスできること
- **FR-002**: ポート番号の入力が不要であること
- **FR-003**: クライアント側の設定変更（hosts編集等）が不要であること
- **FR-004**: 複数のVPN接続端末から同時アクセス可能であること

### 3.2 オプション要件
- **FR-005**: HTTPS対応（将来）
- **FR-006**: ログイン認証機能
- **FR-007**: セッション管理機能

## 4. 非機能要件

### 4.1 性能要件
- **NFR-001**: DNS解決が1秒以内に完了すること
- **NFR-002**: HTTP応答が3秒以内に返ること

### 4.2 可用性要件
- **NFR-003**: サーバー再起動後も自動でサービスが起動すること
- **NFR-004**: DNS障害時もフォールバック可能であること

### 4.3 セキュリティ要件
- **NFR-005**: VPNネットワーク外からのアクセスを制限すること
- **NFR-006**: 管理画面への不正アクセスを防止すること

### 4.4 運用要件
- **NFR-007**: 設定変更が容易であること
- **NFR-008**: ログが適切に記録されること
- **NFR-009**: インターネット接続に影響しないこと

## 5. 制約条件

### 5.1 技術的制約
- **TC-001**: 既存のTailscale VPN環境を使用すること
- **TC-002**: Ubuntu 20.04 LTS上で動作すること
- **TC-003**: Claude Code APIとの接続を維持すること

### 5.2 環境制約
- **EC-001**: サーバーIP: 192.168.1.13（ローカル）/ 100.115.216.73（Tailscale）
- **EC-002**: VPN PCは動的IPアドレス（100.x.x.x）を使用
- **EC-003**: 既存のネットワーク構成を大幅に変更しないこと

## 6. 前提条件
- Tailscale VPNが設定済みであること
- サーバーにsudo権限があること
- ポート80, 53が利用可能であること

## 7. 用語定義
- **VPN PC**: Tailscale経由で接続するクライアントPC
- **home.poco**: カスタムドメイン名
- **MagicDNS**: Tailscaleの内部DNS機能

## 8. 成功基準
1. VPN接続PCのブラウザで `http://home.poco` と入力
2. Webページ（現状: Directory listing）が表示される
3. クライアント側での設定変更なしで動作する
4. 複数端末から同時アクセス可能

## 9. リスクと対策
| リスク | 影響度 | 発生確率 | 対策 |
|--------|--------|----------|------|
| DNS設定ミスによるインターネット接続断 | 高 | 中 | 外部DNSフォワード設定の確実な実装 |
| サービス競合によるポート衝突 | 中 | 低 | サービス整理とポート管理 |
| 設定変更によるClaude Code API接続断 | 高 | 中 | DNS設定の慎重な変更と復旧手順準備 |
