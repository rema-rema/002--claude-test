# 🌐 VPN/DNS Access System - 要件定義書

## 📋 プロジェクト概要

### プロジェクト名
**VPN/DNS Access System (home.poco ドメインアクセスシステム)**

### 背景・目的
Tailscale VPN経由でのみ「home.poco」ドメインでのアクセスを可能にし、開発環境への安全なリモートアクセスを実現する。

### 解決すべき課題
1. **【最重要・未解決】ローカルネットワークアクセス**: 家庭内ネットワークからの直接アクセス実現（現在は技術的制約により未実装、VPN経由で暫定対応）
2. **再起動耐性**: サーバー再起動後も手動作業なしで自動復旧
3. **ネットワーク安定性**: ローカルネットワークに影響を与えない
4. **運用簡素化**: 完全自動化による運用負荷ゼロ
5. **適切なUI表示**: ディレクトリ一覧ではなくダッシュボード/ログイン画面の表示

## 🎯 機能要件

### FR-001: VPN専用ドメインアクセス（暫定実装）
**要件**: 現在はTailscale VPN接続時のみhome.pocoドメインでアクセス可能
- **VPN接続時**: home.poco → 100.115.216.73で解決
- **VPN未接続時**: home.pocoは解決不可（将来的にローカルネットワークからも解決可能にする）
- **MagicDNS統合**: TailscaleのMagicDNS機能を活用
- **将来対応**: ローカルネットワーク（192.168.1.x）からの直接アクセス実現

### FR-002: 完全自動起動
**要件**: サーバー再起動後、すべてのサービスが自動起動
- **DNSサービス**: dnsmasq自動起動
- **Webサーバー**: nginx自動起動  
- **HTTPサーバー**: Python HTTPサーバーのsystemd化
- **設定保護**: /etc/resolv.conf の保護

### FR-003: ローカルネットワーク無影響
**要件**: VPN/DNS設定がローカルネットワークに影響しない
- **DHCP無効**: ローカルDHCPサービスは提供しない
- **DNS分離**: ローカルクライアントはhome.poco解決不可
- **ネットワーク分離**: VPNトラフィックとローカルトラフィックの完全分離

### FR-004: 現状維持ベース実装
**要件**: 既存の動作している構成を基に安定性を最優先
- **設定維持**: 現在動作中の設定を可能な限り維持
- **最小変更**: 必要最小限の変更のみ実施
- **互換性確保**: 既存システムとの完全互換性

### FR-005: ダッシュボード/ログイン画面表示
**要件**: アクセス時に適切なアプリケーションUIを表示
- **初期画面**: ログイン画面またはダッシュボード表示
- **ディレクトリ非表示**: Pythonサーバーのディレクトリ一覧を表示しない
- **アプリケーション連携**: 実際のWebアプリケーションへの適切なルーティング

## 🔒 非機能要件

### NFR-001: 可用性
- **サービス可用性**: 99.9%以上（計画メンテナンス除く）
- **自動復旧**: サービス障害時5秒以内に自動再起動
- **再起動耐性**: OS再起動後1分以内にサービス完全復旧

### NFR-002: セキュリティ
- **アクセス制限**: VPN未接続からのアクセス完全遮断
- **設定保護**: システム設定ファイルの改変防止
- **ログ記録**: すべてのアクセスログを記録・保持

### NFR-003: パフォーマンス
- **DNS応答時間**: 10ms以下
- **HTTP応答時間**: 100ms以下
- **同時接続数**: 100接続以上対応

### NFR-004: 運用性
- **メンテナンスフリー**: 日常的な運用作業不要
- **自動ログローテーション**: ログファイル自動管理
- **監視不要**: 自己回復機能により監視作業不要

## 🚫 制約条件

### 技術制約
- **OS**: Ubuntu Linux（現行環境）
- **VPN**: Tailscale（変更不可）
- **DNSサーバー**: dnsmasq（現行維持）

### 運用制約
- **ダウンタイム**: 実装時の停止時間5分以内
- **ロールバック**: 問題発生時は即座に前バージョンへ復旧可能
- **テスト環境**: 本番環境での直接テスト（別環境なし）
