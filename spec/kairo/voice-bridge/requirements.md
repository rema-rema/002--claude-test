# Discord音声ブリッジ - 要件定義書

## 1. プロジェクト概要

### 1.1 目的
既存のclaude-discord-bridge（テキストベース）に音声I/O機能を追加し、Discord音声チャンネル経由でClaude Codeと会話できるようにする。

### 1.2 ゴール
- ハンズフリーでAIと会話できる環境を構築
- 「肩に乗った妖精と喋る」ような自然な対話体験の実現
- 既存のテキストブリッジ資産を活かした最小改造

### 1.3 スコープ
- **対象**: Discord音声チャンネルでの音声入出力
- **対象外**: テキストチャンネルの既存機能変更

---

## 2. 機能要件

### FR-001: 音声出力（TTS）
**概要**: Claudeの応答テキストを音声化してDiscord音声チャンネルで再生

**詳細**:
- dpコマンド（bin/dp）でDiscordにテキスト送信するタイミングでTTSを呼び出す
- テキストをTTSエンジンで音声化
- 音声をDiscord音声チャンネルにストリーミング送信
- テキストチャンネルへの送信と並行して動作

**応答キャプチャ方式**:
```
Claude Code → dpコマンド → Discord テキストCh送信
                     ↓
              同時にTTS → Discord音声Ch送信
```

**受け入れ条件**:
- [ ] テキストチャンネルにメッセージ送信後、音声チャンネルで応答が再生される
- [ ] 日本語テキストが正しく音声化される

### FR-002: 音声入力（STT）
**概要**: ユーザーの音声をテキスト化してClaude Codeに転送

**詳細**:
- Discord音声チャンネルでユーザーの音声を受信
- STTエンジンでテキスト化
- 既存のテキストパイプライン（Claude Code転送）に接続

**受け入れ条件**:
- [ ] 音声チャンネルで話した内容がClaude Codeに転送される
- [ ] 日本語音声が正しくテキスト化される

### FR-003: 音声チャンネル参加
**概要**: Botが音声チャンネルに参加・退出できる

**詳細**:
- コマンドまたは自動でBotが音声チャンネルに参加
- 退出コマンドまたは自動退出機能

**受け入れ条件**:
- [ ] Botが指定した音声チャンネルに参加できる
- [ ] Botが音声チャンネルから退出できる

### FR-004: トリガー方式
**概要**: 段階的なトリガー方式の実装

**Phase 1（初期）: Push-to-Talk方式**
- Discord側のPush-to-Talk設定に依存
- ユーザーがキーを押している間のみ音声を受信
- 追加開発不要（Discord既存機能を利用）

**Phase 2（将来）: ウェイクワード方式**
- 「クロード、○○して」のようなキーワードで起動
- VAD（Voice Activity Detection）と組み合わせ
- スコープ外として将来拡張で対応

**受け入れ条件**:
- [ ] Push-to-Talk中の音声のみが処理される（Phase 1）

## 3. 非機能要件

### NFR-001: レイテンシ
- TTS応答開始まで: 3秒以内（目標）
- STTテキスト化: 発話終了から2秒以内（目標）

### NFR-002: 音声品質
- サンプリングレート: 48kHz（Discord標準）
- 日本語対応必須

### NFR-003: 既存機能への影響
- テキストチャンネルの既存機能に影響を与えない
- 音声機能はオプション（音声チャンネル未参加時は従来通り動作）

### NFR-004: エラーハンドリング
- TTS失敗時: テキストチャンネルへの送信は継続、エラーログ出力
- STT認識失敗時: 「聞き取れませんでした」と音声で応答、リトライ促す
- 音声チャンネル接続失敗時: テキストチャンネルにエラー通知

### NFR-005: 長文応答の処理
- 長文は分割して順次読み上げ
- 読み上げ中に新しい入力があった場合の動作は将来検討（初期は読み上げ完了まで待機）

## 4. 技術要件

### 4.1 Discord設定（ユーザー作業）

**必要なチャンネル**:
- **音声チャンネル**: 1つ（作成済み）
  - チャンネルID: `1448208103589019678`
  - Botに接続権限が必要

**Bot権限追加**:
- `Connect` - 音声チャンネルへの接続
- `Speak` - 音声チャンネルでの発言
- `Use Voice Activity` - 音声アクティビティの検出（任意）

**テキストチャンネル**: 既存のものをそのまま使用

### 4.2 TTSエンジン
**第一候補**: VOICEVOX
- 日本語対応
- 無料・ローカル実行
- 高品質な音声合成
- **環境構築**: DockerでAPIサーバーとして起動

**代替候補**: ElevenLabs
- 高品質だが有料
- 月額課金

### 4.3 STTエンジン
**第一候補**: Whisper API（OpenAI）
- 高精度
- 日本語対応
- **コスト**: $0.006/分（従量課金）

**代替候補**: ローカルWhisper
- 無料だがリソース消費大
- GitHub Codespacesでは重い可能性

### 4.4 Discordライブラリ
- Python: `discord.py[voice]`
- 依存: `PyNaCl`, `ffmpeg`

## 5. 制約事項

- GitHub Codespaces環境での動作を想定

- 既存のclaude-discord-bridgeの構造を大きく変更しない
